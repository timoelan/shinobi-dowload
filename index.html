VinoGames Launcher

Ein Programm für alle Spiele: anmelden, installieren, automatische Updates, spielen.

Installieren

Mac

  1. ZIP öffnen (Doppelklick).
  2. VinoGames.app (Launcher) in den Ordner Programme ziehen.
  3. Rechtsklick auf die App → Öffnen → nochmals Öffnen.
  4. Meldung „beschädigt“? Terminal öffnen und eingeben:
    xattr -cr "/Applications/VinoGames.app"

Windows

  1. ZIP entpacken (Rechtsklick → Alle extrahieren).
  2. VinoGames.exe starten.
  3. SmartScreen: Weitere Informationen → Trotzdem ausführen.
  4. Firewall-Frage: Zulassen (privates Netzwerk).

Im Launcher

  1. Mit deinem Konto anmelden.
  2. Store → Spiel → Kostenlos holen.
  3. Bibliothek → Installieren → Spielen. Updates kommen automatisch.

Online spielen

  1. Tailscale installieren.
  2. Einladung in die Gruppe annehmen und anmelden.
  3. Im Spiel: Kämpfen → Online → Lobby erstellen oder Code eingeben.
